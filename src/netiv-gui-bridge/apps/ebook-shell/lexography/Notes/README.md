# Notes Contract

Notes in this folder are rendered as editable markdown documents.

## File Rules

| Folder | Extension | Purpose |
|---|---|---|
| Notes | `.md` | Notebook-style prose, headings H1-H4, lists, tables, and code blocks |

## Rendering Contract

```markdown
# Heading 1
## Heading 2
### Heading 3
#### Heading 4
- Bullet items
> Block quotes
`inline code`
```

The Notes tab should show the selected markdown file in the main viewport, list only compatible `.md` files in the selector, and allow saving or creating new note files.
