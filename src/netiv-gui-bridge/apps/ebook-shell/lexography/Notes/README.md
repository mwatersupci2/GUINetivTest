# Notes Contract

Notes in this folder are rendered as markdown documents.

## File Rules

| Folder | Extension | Purpose |
|---|---|---|
| Notes | `.md` | Notebook-style prose, lists, tables, and code blocks |

## Rendering Contract

```markdown
# Heading 1
## Heading 2
- Bullet items
> Block quotes
`inline code`
```

The Notes tab should show the selected markdown file in the main viewport and list only compatible `.md` files in the selector.
